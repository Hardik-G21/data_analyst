Marketing ROI Suite

Overview
This project is a production-ready Marketing ROI Dashboard designed to analyze a ₹6,00,000 marketing budget across multiple channels.  
It focuses on identifying underperforming campaigns, understanding revenue drivers, and providing actionable business recommendations.

Objectives
- Detect failed ad campaigns using Z-score analysis  
- Identify key factors influencing revenue using correlation  
- Build an executive-level dashboard for decision-making  
- Provide strategic recommendations for budget optimization  

Dataset
The dataset contains:
- Date  
- Channel (Google Ads, Facebook, Instagram, LinkedIn)  
- Spend  
- Revenue  
- Clicks  
- Impressions  

Technologies Used
- Python  
- Pandas  
- NumPy  
- Seaborn  
- Matplotlib  

Key Features

1. Outlier Detection (Z-Score)
- Identifies low-performing campaigns  
- Helps detect inefficient spending  

2. Correlation Analysis
- Finds relationships between:
  - Spend
  - Revenue
  - Clicks
  - Impressions  

3. Executive Dashboard
Includes:
- ROI Trend over time  
- Revenue by Channel  
- Correlation Heatmap  
- Spend vs Revenue Scatter Plot  

4. Strategic Recommendation
- Highlights the best-performing channel  
- Suggests where to allocate budget for maximum ROI  

Business Insight
The analysis revealed that certain channels consistently deliver higher ROI.  
By reallocating budget from underperforming campaigns to high-performing ones, overall marketing efficiency can be significantly improved.

Problem Solved
Traditional analysis focuses only on numbers (averages, totals).  
This project bridges the gap between theory and execution by:
- Identifying failed campaigns  
- Explaining *why* they failed  
- Recommending actionable steps
